1. Multi-Tenant Request Lifecycle & Zero-Leakage Data Isolation

Core Isolation Principle

Every inbound HTTP request to the Spring Boot backend follows a strict 5-stage isolation pipeline to prevent cross-company data leakage:

1

HTTP Header Transport

Frontend sends Authorization: Bearer <JWT> and X-Tenant-ID: <CompanyID> with every request.

2

Tenant Security Filter

TenantFilter intercepts request, extracts tenant ID, and validates membership in the database before processing.

3

ThreadLocal Context

TenantContext.setCurrentTenant(id) binds the tenant to the executing thread for zero-argument context passing.

4

SQL Discriminator Injection

JPA Repositories append WHERE tenant_id = ? to guarantee that Company A never sees Company B's data.

5

Safe Finally Cleanup

finally { TenantContext.clear() } removes ThreadLocal state to prevent thread reuse contamination in Tomcat.

How to Connect Free Email Services (Gmail, Brevo, Resend)

1. Gmail SMTP (100% Free)

Send up to 500 emails/day using your standard Google account:

  1. Enable 2-Step Verification on your Google Account.
  2. Visit myaccount.google.com/apppasswords.
  3. Generate an App Password (name it "NexSpace"). You'll receive a 16-character key.
  4. In application.yml or environment variables: 
    SPRING_MAIL_HOST=smtp.gmail.com
SPRING_MAIL_PORT=587
SPRING_MAIL_USERNAME=your.email@gmail.com
SPRING_MAIL_PASSWORD=your16charpassword
APP_MAIL_FROM=your.email@gmail.com

2. Brevo / Sendinblue (Free 300/Day)

Zero credit card needed, free tier sends 300 emails per day to any domain:

  1. Sign up free at brevo.com.
  2. Go to Transactional > SMTP & API.
  3. Copy your SMTP Master Key.
  4. Configure: 
    SPRING_MAIL_HOST=smtp-relay.brevo.com
SPRING_MAIL_PORT=587
SPRING_MAIL_USERNAME=your-brevo-login-email
SPRING_MAIL_PASSWORD=your-brevo-smtp-key
APP_MAIL_FROM=verified-sender@domain.com

Multi-tenant workspace operations guide

Multi-Tenant Partition Isolation

NexSpace uses a shared MySQL database architecture partitioned with a strict discriminator column (tenant_id). All HTTP requests propagate the X-Tenant-ID header, which Spring Boot filters into a thread-bound TenantContext to ensure 100% data isolation between organizations.

Role Boundaries & RBAC

• OWNER: Full authority, tenant settings & deletion.
• ADMIN: Manage team members, projects & tasks.
• BILLING_ADMIN: Isolated access to Stripe upgrades, invoices & webhooks.
• MEMBER: Create and update tasks & project items.
• VIEWER: Read-only access to cards and timelines.
